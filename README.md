# Web2APK Builder

Android app that turns a website or a ZIP archive into an installable APK.
The long-term goal is to build the APK entirely on the device, with no PC.

> Personal project. Not intended for Google Play distribution.

## Status

Early development. Current version: **v0.1 (skeleton)**.

## Stack

Kotlin · Jetpack Compose · Material 3 · Min SDK 26 · package `com.web2apk.builder`

## Roadmap

| Version | Goal |
|---------|------|
| v0.1 | Project skeleton |
| v0.2 | ZIP import |
| v0.3 | Android project generation |
| v0.4 | Local APK build and signing |
| v1.0 | Release |

## Principle

An APK generated from a site must keep everything that works on the site.
